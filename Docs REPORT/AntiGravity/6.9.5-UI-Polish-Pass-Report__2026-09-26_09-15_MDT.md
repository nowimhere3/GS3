### 1. Why the Follow Along Checkbox Was Invisible

In modern ChatGPT, CSS resets and preflight stylesheets (notably Tailwind CSS) apply aggressive resets across all native form controls:
```css
input[type="checkbox"], input[type="radio"] {
  appearance: none;
  -webkit-appearance: none;
  padding: 0;
  margin: 0;
  width: 0;
  height: 0;
  background-color: transparent;
  border: none;
}
```
In `6.9.4`, `#cgpt-reader-autoopen` had only:
```css
.cgpt-settings-toggle input { margin: 2px 0 0; accent-color: #10a37f; flex: none; cursor: pointer; }
```
Because `appearance: none` and zero-width/height/border reset rules had higher specificity or inheritance from the host page reset, the native browser checkbox glyph was stripped completely, leaving a 0×0 or transparent hit-box with no visual presence beside the label.
