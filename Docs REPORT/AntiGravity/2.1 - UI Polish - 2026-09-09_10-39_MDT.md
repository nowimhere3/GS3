## 3. Detailed Changes

### 3.1 Change 1: Settings Layout Icons Need Real Button Shells
* **Problem:** Settings Grid Layout Order rows previously rendered naked mini-floorplans without borders or button wrappers directly inside `.hotswap-toggle-label`, appearing like magnified, unfinished diagrams.
* **Implementation:**
  * In [`js/settings.js`](file:///C:/Users/dmcal/Documents/GitHub/GS3/js/settings.js#L366-L377), updated the `rowFactory` for `grid-layout-shortcuts-config` to wrap `${getLayoutIconMarkup(id)}` in `<span class="layout-btn-shell layout-btn">`.
  * In [`settings.html`](file:///C:/Users/dmcal/Documents/GitHub/GS3/settings.html#L340-L358), defined `.layout-btn-shell`:
    * Visible border: `1px solid #333` (hover: `#555`)
    * Dark shell background: `#1a1a1a` (hover: `#252525`)
    * Rounded corners: `border-radius: 8px`
    * Compact padding: `padding: 5px 8px` (yielding a 42×30px control box)
    * Spacing: `gap: 10px` on `.hotswap-toggle-label` separating the `☰` drag handle, the button shell, and the title.
  * Visual inspection confirmed rows read clearly as `[☰] [ bordered mini button ] [human-readable title]` with subtle dimming (`opacity: 0.48`) preserved for outside-cutoff rows.

### 3.2 Change 2: Move Grid Layout Shortcut Settings Lower
* **Problem:** The `grid-layouts` config card was placed at index 0 of the `order` array in `_initCollapsibleSections()`, causing it to render at the very top of Settings above GitHub sync, Ingest, and Hotswap controls.
* **Required Hierarchy:**
  1. Toolbar Shortcuts
  2. Quick Action Runway
  3. Grid Layout Shortcuts
* **Implementation:**
  * In [`js/settings.js`](file:///C:/Users/dmcal/Documents/GitHub/GS3/js/settings.js#L92-L99), updated the `order` array:
    `const order = ['github', 'ingest', 'hotswap', 'grid-layouts', 'folders', 'frame-heights', 'ghost', 'blacklist'];`
  * In [`settings.html`](file:///C:/Users/dmcal/Documents/GitHub/GS3/settings.html#L538-L650), rearranged static markup so `hotswap` and `grid-layouts` follow `ingest` and precede `folders` and `frame-heights`.
  * Verified in document order:
    * `Toolbar Shortcuts` (sub-section of `Top Toolbar` within `hotswap`)
    * `<` `Quick Action Shortcut Runway` (surface within `hotswap`)
    * `<` `Grid Layout Shortcuts` (`grid-layouts` card following `hotswap`)
  * Exactly one `Grid Layout Shortcuts` section UI exists. Count (1–4), default (2), drag-ordering, and localStorage persistence (`grid_layout_slot_count` and `grid_layout_slot_order`) are preserved.

### 3.3 Change 3: Polish GS3-Owned Scrollbars
* **Ownership Finding:**
  * An embedded `<iframe>` running arbitrary third-party or cross-origin content owns its own scrollbars inside its isolated browsing context. Cross-origin browser security policies prevent host stylesheets from penetrating or styling these scrollbars.
  * Attempting to inject CSS into third-party iframes is blocked by CORS/same-origin policy and prohibited by architectural guidelines.
  * GS3 legitimately and directly owns all host-level scrolling surfaces: the Settings page, `#blacklist-display`, Master dropups (`#master-folder-dropup`, `#master-save-dropup`), Hotswap position/folder menus (`.hotswap-position-menu`, `.hotswap-folder-row`), and same-origin nested Runtimes (Layer 2).
* **Styling Applied:**
  * In [`settings.html`](file:///C:/Users/dmcal/Documents/GitHub/GS3/settings.html#L9-L18), [`index3.html`](file:///C:/Users/dmcal/Documents/GitHub/GS3/index3.html#L55-L64), [`index2.html`](file:///C:/Users/dmcal/Documents/GitHub/GS3/index2.html#L55-L64), and [`index.html`](file:///C:/Users/dmcal/Documents/GitHub/GS3/index.html#L81-L91):
    ```css
    html { color-scheme: dark; }
    * {
        scrollbar-color: #666 #1a1a1a;
        scrollbar-width: thin;
    }
    ::-webkit-scrollbar {
        width: 8px;
        height: 8px;
    }
    ::-webkit-scrollbar-track {
        background: #1a1a1a;
    }
    ::-webkit-scrollbar-thumb {
        background: #666;
        border-radius: 4px;
    }
    ::-webkit-scrollbar-thumb:hover {
        background: #777;
    }
    ::-webkit-scrollbar-corner {
        background: #1a1a1a;
    }
    ```
  * Track: `#1a1a1a` (dark charcoal)
  * Thumb: `#666` (medium gray / soft off-gray)
  * Thumb hover: `#777` (slightly lighter gray)
  * Corner: `#1a1a1a`
