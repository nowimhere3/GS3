## 1. Executive Summary

A deep architectural and DOM inspection was performed to identify the ownership, selectors, and suppression pathways for two unwanted in-panel website controls:
1. The visible `8 Sec` timer/countdown control
2. The large floating red Heart control at the lower/right side

**Core Finding & Fence Boundary:**
Both controls are owned strictly by **cross-origin third-party documents loaded inside `<iframe>` stream slots** (primarily `elitebabes.com`, which is configured across default presets like Preset 1). Under standard browser security (Same-Origin Policy), the GS3 parent runtime cannot access or manipulate the DOM/CSS inside cross-origin iframes.

Furthermore, **no existing content-injection mechanism, Tampermonkey bridge, or extension content-script pathway currently exists within the GS3 project**. In accordance with the explicit scope boundary instruction:
> *"If they cannot be removed from GS3 because they belong to cross-origin iframe content and no existing injection mechanism reaches them, STOP and report: which site/document owns them, the exact selectors if discoverable, what mechanism would be required to remove them safely"*

Implementation was stopped at the scope fence. No host overlays were created, and browser security boundaries were strictly preserved.

## 4. Required Safe Suppression Mechanism

Because GS3 cannot penetrate cross-origin iframes without violating browser security or resorting to brittle DOM overlays that block clicks to underlying content:

### Supported Solution: Userscript / Extension Content Script
The clean, web-standard method to suppress these elements inside third-party iframe streams is via a client-side stylesheet injection tool (Tampermonkey, Violentmonkey, or a companion browser extension) operating with `all_frames: true`:

```css
/* Targeted In-Panel Suppression Rule */
/* Matches: *://*.elitebabes.com/* */
.fancybox-speed,
.swiper-speed,
.fancybox-toolbar .fancybox-speed,
.rating-a li.a,
.cols-add-trigger,
.wp_ulike_btn_is_active,
.icon-favorite {
    display: none !important;
    visibility: hidden !important;
    pointer-events: none !important;
}
```

If packaged as an extension or userscript with `run_at: "document_start"` and `all_frames: true`, the browser engine will silently suppress both controls on load before first paint, without affecting GS3 shell code or breaking cross-origin isolation.
